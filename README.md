# Game Hub — Каталог компьютерных игр

Веб-приложение каталога и магазина компьютерных игр, разработанное в рамках учебного практикума (ПМ.03). 

Проект реализован как **чистое статическое клиентское приложение** без серверного бэкенда и без сборщиков (no build tools), использующее **Vanilla JavaScript (ES6+ модули)** и облачную бессерверную платформу **Google Firebase (Spark Tier)**.

## 🛠 Технологический стек и ограничения

- **Фронтенд:** Vanilla JavaScript (ES6+ Modules), семантический HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid).
- **Фреймворки:** Отсутствуют (React, Vue, Vite, Webpack не используются). Проект готов к немедленному открытию в браузере или хостингу на GitHub Pages.
- **Облачная платформа:** Firebase 10.12 (CDN ESM-бандл):
  - **Firebase Authentication:** Вход по Email/Паролю, Google Sign-In, восстановление пароля по почте.
  - **Cloud Firestore:** NoSQL база данных реального времени, транзакции, пакетные записи (batch writes), курсорная пагинация (`startAfter`).
  - **Firebase Storage:** Хранение обложек игр, скриншотов и видеороликов геймплея.
  - **Security Rules:** Декларативные политики разграничения прав доступа на уровне строк и коллекций Firestore и Storage.

## 🚀 Пошаговая инструкция по установке и настройке Firebase

### Шаг 1. Создание проекта в Firebase Console
1. Перейдите на [Firebase Console](https://console.firebase.google.com/) и войдите в свой Google-аккаунт.
2. Нажмите **«Add project»** (Создать проект) и укажите имя (например, `game-hub-student`).
3. Google Analytics можно отключить (не требуется) и нажмите **«Create project»**.

### Шаг 2. Регистрация веб-приложения
1. На главной странице проекта нажмите на иконку веб-приложения `</>` (Web).
2. Укажите название приложения (например, `Game Hub Web`). Флажок Firebase Hosting ставить необязательно (используется GitHub Pages).
3. Скопируйте предоставленный объект конфигурации `firebaseConfig`.

### Шаг 3. Вставка ключей в проект
Откройте файл `js/firebase-config.js` в вашем репозитории и замените плейсхолдеры на ваши реальные значения:

```javascript
const firebaseConfig = {
  apiKey:            "ВАШ_API_KEY",
  authDomain:        "ВАШ_AUTH_DOMAIN",
  projectId:         "ВАШ_PROJECT_ID",
  storageBucket:     "ВАШ_STORAGE_BUCKET",
  messagingSenderId: "ВАШ_MESSAGING_SENDER_ID",
  appId:             "ВАШ_APP_ID"
};
```

### Шаг 4. Включение Authentication
1. В левом меню консоли Firebase выберите **Build → Authentication**.
2. Нажмите **Get Started**.
3. Во вкладке **Sign-in method** включите провайдеры:
   - **Email/Password**: переведите переключатель в положение Enable и сохраните.
   - **Google**: переведите в положение Enable, укажите контактный email поддержки и сохраните.
4. Во вкладке **Settings → Authorized domains** убедитесь, что добавлен домен `localhost` и домен `YOUR_USERNAME.github.io` для работы авторизации на GitHub Pages.

### Шаг 5. Включение Cloud Firestore
1. В меню выберите **Build → Firestore Database** и нажмите **Create database**.
2. Выберите регион (например, `eur3 (europe-west)` или ближайший) и выберите **Start in production mode**.
3. Перейдите во вкладку **Rules** и скопируйте содержимое файла [`firestore.rules`](firestore.rules) из этого репозитория. Нажмите **Publish**.

### Шаг 6. Включение Cloud Storage
1. В меню выберите **Build → Storage** и нажмите **Get Started**.
2. Выберите режим **Start in production mode**.
3. Перейдите во вкладку **Rules** и скопируйте содержимое файла [`storage.rules`](storage.rules) из этого репозитория. Нажмите **Publish**.

### Шаг 7. Назначение первого администратора и первичное наполнение (Seed)
1. Откройте `login.html` в браузере и зарегистрируйте ваш основной аккаунт.
2. Откройте Firebase Console → **Firestore Database** → коллекция `users` → откройте документ с вашим UID.
3. Измените поле `role` со значения `"user"` на значение `"admin"`.
4. Обновите страницу сайта — в шапке появится бейдж **«АДМИН»** со ссылкой на `admin.html`.
5. Перейдите в админ-панель на вкладку **«База данных (Seed)»** и нажмите **«Заполнить базу игр (Seed)»**. Скрипт создаст 4 образца игр (*Cyberpunk 2077*, *Elden Ring*, *Zelda TotK*, *Hades*) с полным набором характеристик и системных требований.

## 📦 Развертывание на GitHub Pages

1. Запушьте код проекта в репозиторий на GitHub:
   ```bash
   git add .
   git commit -m "Game Hub: complete project"
   git push origin main
   ```
2. Откройте страницу репозитория на GitHub: **Settings → Pages**.
3. В разделе **Build and deployment → Branch** выберите ветку `main` (или `master`) и папку `/(root)`.
4. Нажмите **Save**. Спустя 1–2 минуты сайт станет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
5. Добавьте полученный URL в Firebase Console → **Authentication → Settings → Authorized domains**, чтобы Google Sign-In работал на домене GitHub Pages.
