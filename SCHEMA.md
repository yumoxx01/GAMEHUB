# Game Hub — Database Schema Documentation

Документация архитектуры данных, схемы коллекций, композитных индексов и политик безопасности базы данных Firestore и Cloud Storage для веб-приложения **Game Hub**.

---

## 1. Схема коллекций Firestore

### 1.1. Коллекция `users`
Путь к документу: `users/{uid}` (где `uid` соответствует UID пользователя в Firebase Authentication)  
**Назначение:** Хранение профилей зарегистрированных пользователей и их ролей доступа.

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `displayName` | `string` | Отображаемое имя пользователя (никнейм) |
| `email` | `string` | Адрес электронной почты (синхронизирован с Auth) |
| `role` | `"user" \| "admin"` | Роль в системе. По умолчанию `"user"`. Доступ к `"admin"` выдается другим администратором |
| `createdAt` | `timestamp` | Дата и время регистрации аккаунта |
| `photoURL` | `string` *(опционально)* | Ссылка на аватар пользователя (из Google Auth или Storage) |
| `bio` | `string` *(опционально)* | Краткая информация о пользователе / любимые жанры |

---

### 1.2. Коллекция `games`
Путь к документу: `games/{gameId}`  
**Назначение:** Центральный каталог компьютерных игр с описаниями, ценами, системными требованиями и денормализованным рейтингом.

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `title` | `string` | Название игры |
| `titleLower` | `string` | Название в нижнем регистре для регистронезависимого поиска |
| `description` | `string` | Полное описание сюжета и игрового процесса |
| `coverImage` | `string` | Путь в Storage или публичный URL обложки (16:9) |
| `genres` | `array<string>` | Список жанров (Action, RPG, Strategy, Adventure и т.д.) |
| `platforms` | `array<string>` | Поддерживаемые платформы (`PC`, `PlayStation`, `Xbox`, `Nintendo`) |
| `releaseDate` | `timestamp` | Официальная дата выхода игры |
| `developer` | `string` | Студия-разработчик игры |
| `publisher` | `string` | Компания-издатель игры |
| `price` | `number` | Стоимость игры в рублях (0 = бесплатно) |
| `hardwareRequirements` | `map` | Системные требования для запуска игры |
| `hardwareRequirements.min` | `map` | Минимальные требования: `{ cpu, gpu, ram, storage }` |
| `hardwareRequirements.rec` | `map` | Рекомендованные требования: `{ cpu, gpu, ram, storage }` |
| `screenshots` | `array<string>` | Массив ссылок/путей на скриншоты для галереи |
| `videoURL` | `string` | Ссылка или Storage-путь на видеоролик (геймплей/трейлер) |
| `featured` | `boolean` | Флаг участия в случайной ротации баннера на главной странице |
| `avgRating` | `number` | Денормализованный средний рейтинг (1.0–5.0), пересчитываемый транзакционно |
| `reviewCount` | `number` | Денормализованное общее количество отзывов |
| `createdAt` | `timestamp` | Время добавления игры в каталог |
| `createdBy` | `string` (uid) | UID администратора, создавшего запись |

---

### 1.3. Коллекция `reviews`
Путь к документу: `reviews/{reviewId}`  
**Назначение:** Оценки и текстовые рецензии пользователей к играм.

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `gameId` | `string` | Идентификатор обозреваемой игры (`games/{gameId}`) |
| `userId` | `string` | UID автора отзыва (`users/{uid}`) |
| `userName` | `string` | Денормализованное имя автора на момент написания |
| `rating` | `number` (1–5) | Оценка игры по шкале от 1 до 5 звезд |
| `text` | `string` | Текст отзыва |
| `createdAt` | `timestamp` | Дата и время публикации отзыва |
| `updatedAt` | `timestamp` *(опц.)* | Время последнего редактирования отзыва |

---

### 1.4. Коллекция `cart`
Путь к документу: `cart/{userId}_{gameId}` (составной ключ)  
**Назначение:** Активные корзины пользователей перед оформлением заказа.

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `userId` | `string` | UID владельца корзины |
| `gameId` | `string` | Идентификатор добавленной игры |
| `gameTitle` | `string` | Денормализованное название игры на момент добавления |
| `gameCover` | `string` | Денормализованная ссылка на обложку для быстрого рендеринга |
| `price` | `number` | Денормализованная цена на момент добавления в корзину |
| `quantity` | `number` | Количество копий (минимум 1) |
| `addedAt` | `timestamp` | Время добавления товара в корзину |

---

### 1.5. Коллекция `orders`
Путь к документу: `orders/{orderId}`  
**Назначение:** Оформленные заказы пользователей (история покупок и чеки).

| Поле | Тип | Назначение |
| :--- | :--- | :--- |
| `userId` | `string` | UID покупателя |
| `items` | `array<map>` | Снимок купленных товаров: `[{ gameId, gameTitle, price, quantity }]` |
| `total` | `number` | Итоговая сумма заказа в рублях |
| `status` | `"pending" \| "completed" \| "cancelled"` | Статус заказа: «В обработке», «Выполнен», «Отменен» |
| `createdAt` | `timestamp` | Дата и время оформления заказа |

## 2. Необходимые композитные индексы (Composite Indexes)

Firestore требует создания композитных индексов для запросов, сочетающих фильтрацию по нескольким полям или условие равенства/массива с сортировкой по другому полю.

| Коллекция | Поля и направление | Назначение и контекст применения |
| :--- | :--- | :--- |
| `games` | `genres` (array-contains) + `releaseDate` (desc) | Фильтрация каталога по жанру с сортировкой по дате выхода новинок |
| `games` | `platforms` (array-contains) + `avgRating` (desc) | Фильтрация каталога по платформе с сортировкой по популярности/рейтингу |
| `reviews` | `gameId` (==) + `createdAt` (desc) | Вывод списка отзывов к конкретной игре в обратном хронологическом порядке |
| `cart` | `userId` (==) + `addedAt` (desc) | Загрузка содержимого корзины пользователя по времени добавления |
| `orders` | `userId` (==) + `createdAt` (desc) | Отображение истории покупок пользователя в личном кабинете |

> **Примечание по созданию индексов:** При первом выполнении комбинированного запроса SDK Firebase генерирует в консоли браузера прямую ссылку на создание индекса в панели Firebase Console в один клик.

## 3. Политики безопасности (Security Rules Logic)

### 3.1. Firestore (`firestore.rules`)
1. **`users/{uid}`:**
   - Чтение: разрешено владельцу документа (`request.auth.uid == uid`) или администратору (`users/{adminUid}.role == 'admin'`).
   - Создание: разрешено любому аутентифицированному пользователю для своего документа, при этом поле `role` принудительно фиксируется как `'user'`.
   - Обновление: обычный пользователь может изменять профиль (`displayName`, `bio`), но не может изменять значение поля `role`. Администраторы имеют полный доступ к изменению ролей.
2. **`games/{gameId}`:**
   - Чтение: публично доступно всем (включая неавторизованных посетителей).
   - Создание и удаление: строго разрешено только администраторам.
   - Обновление: разрешено администраторам, а также авторизованным пользователям **исключительно** для атомарного пересчета полей `avgRating` и `reviewCount` (`request.resource.data.diff(resource.data).affectedKeys().hasOnly(['avgRating', 'reviewCount'])`) в рамках транзакций отзывов. Все остальные поля остаются закрытыми от не-админов.
3. **`reviews/{reviewId}`:**
   - Чтение: публично доступно всем.
   - Создание: разрешено авторизованным пользователям только с указанием собственного `userId`.
   - Редактирование: разрешено только автору отзыва.
   - Удаление: разрешено автору отзыва или администратору (для модерации контента).
4. **`cart/{cartId}` (`{userId}_{gameId}`):**
   - Чтение, запись, удаление: доступны только владельцу, чей `request.auth.uid` совпадает с префиксом ID документа и полем `userId`.
5. **`orders/{orderId}`:**
   - Чтение и создание: разрешены только владельцу заказа; при создании статус обязан быть `'pending'`.
   - Обновление: статус заказа (`status`) могут изменять исключительно администраторы.

### 3.2. Cloud Storage (`storage.rules`)
- Путь: `/games/{gameId}/{allPaths=**}`
- Чтение: публичное (обложки, скриншоты и видеофайлы доступны всем посетителям каталога).
- Запись: разрешена только пользователям, у которых в документе `users/$(request.auth.uid)` поле `role == 'admin'` (проверяется через кросс-сервисный вызов `firestore.get()`).
